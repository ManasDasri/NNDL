Clause Risk Review

A neural network course project · multi-label classification of contract clauses on CUAD v1

Commercial contracts are long, and a handful of clauses carry most of the risk. This project trains models to read a contract and flag which of six risk-relevant clause types it contains:

  • Cap on Liability – a limit on how much one party can be made to pay
  • Non-Compete – a restriction on competing with the other party
  • License Grant – a right to use intellectual property
  • Audit Rights – a right to inspect the other party's records
  • Termination for Convenience – a right to end the contract without cause
  • Insurance – a requirement to hold insurance

A contract can contain several of these at once, so the model makes six independent yes/no decisions rather than choosing one label.

What the model does

  1. Reads the data. CUAD v1 is 510 real contracts in which lawyers marked where each clause appears. 358 contracts are used for training, 76 for tuning, and 76 are held back for the final test.
  2. Cuts each contract into windows. The median contract is 5,039 words, far more than a model can read at once, so each contract is cut into overlapping windows of 300 words (2,600 for Longformer).
  3. Labels each window. A window is marked with a clause type only if it actually overlaps a clause the lawyers marked.
  4. Trains a classifier. For every window, the model outputs six probabilities, one per clause type. 85% of windows contain no clause at all, so mistakes on real clauses are weighted more heavily during training.
  5. Picks a cutoff per clause type. Each clause type gets its own yes/no threshold, chosen on the tuning contracts and never on the test contracts.
  6. Combines windows into one answer per contract. Every window counts as a separate piece of evidence, using a rule called noisy-OR (explained below).

All scores are on the 76 test contracts, which no model saw during training or tuning. F1 balances missed clauses against false alarms. AP (average precision) measures how well the model ranks real clauses above false ones. Both run from 0 to 1, higher is better.

Question 1: does pretraining on legal text help?

No measurable advantage. Legal-BERT scored 0.005 below BERT on window F1. For scale, BERT trained twice with different random seeds differed from itself by 0.006. Legal-BERT ranked slightly better (window AP 0.769 against 0.736), and the two tie at contract level. Legal-BERT was trained once, so its small ranking edge is not yet confirmed.

We expected legal pretraining to help most on clause types full of legal jargon. That did not happen: Cap on Liability, the most jargon-heavy, gained nothing. The only clear gain was Termination for Convenience. Both BERT models clearly beat the CNN, most of all on the rarest clause type, Non-Compete (0.317 to 0.560).

Question 2: does reading more of the contract at once help?

No. It scored lower. Longformer reads 2,600 words per window against BERT's 300, yet it finished 0.058 contract F1 below BERT, about twice the noise level, and below the CNN as well.

Two likely reasons. These clauses can usually be recognised from their own sentence, so extra surrounding text adds little. And bigger windows mean fewer of them: 1,380 training windows against BERT's 13,829.

Because of that, Longformer needed ten passes over the data where BERT needed three. Its validation F1 after each pass:

Combining windows: noisy-OR

Each window gets its own score, but the question is about the whole contract. The first version of this project kept only the highest-scoring window. That throws evidence away: a contract with two windows at 0.80 and 0.79 got the same score as one with windows at 0.80 and 0.02.

Noisy-OR treats every window as a separate witness. The clause is missing only if every witness is wrong:

P(clause) = 1 − (1 − p1) × (1 − p2) × …

Measured on the CNN's predictions, noisy-OR scored 0.846 F1 and 0.904 AP against 0.840 and 0.899 for the highest-window rule. That difference is within the noise, so it is not claimed as a win. Noisy-OR is used because it counts all the evidence and was never worse. Simply averaging the windows was far worse, at 0.511 F1.

Limits

  • Trained on 358 contracts. The rarest clause types are the weakest.
  • Legal-BERT and Longformer were each trained once; BERT twice.
  • CUAD is US commercial contracts. Other kinds of contract are untested.
  • This is a research project and not legal advice.
